# Repositorio del curso: Análisis de Algoritmos

Este repositorio contiene el material del curso **Análisis de Algoritmos** que se entrega a lo largo del semestre. Aquí se almacenan los informes de laboratorio, los ejercicios desarrollados en clase y los scripts de medición (benchmarks) que sirven de apoyo para los análisis de complejidad.

## Autor

- **Nombre:** Juan David Machado Mosquera

## Estructura del repositorio

El repositorio se organiza en tres carpetas principales, más este `README.md` y un archivo `.gitignore` en la raíz:

- `laboratorios/`: aquí se entregarán los cinco informes de laboratorio evaluativos del curso. Más adelante, cada informe tendrá su propia subcarpeta.
- `ejercicios-clase/`: contiene el código desarrollado durante las sesiones prácticas no evaluativas, incluidos los ejercicios de Python de la Semana 2.
- `benchmarks/`: aloja los scripts compartidos de medición de tiempos y graficación que se reutilizan en los laboratorios evaluativos para comparar el desempeño de los algoritmos.

## Uso

```bash
# Clonar el repositorio
git clone https://github.com/<usuario>/curso-analisis-algoritmos.git

# Entrar al directorio del proyecto
cd curso-analisis-algoritmos

# Verificar el estado de los archivos
git status
```
